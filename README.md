# 🕵️ ШПиК — база пар слов для игры «Кто шпион»

Веб-интерфейс для ведения личной базы пар слов для игры «Кто шпион / Spyfall».

## Возможности

- **➕ Добавление пар слов** — вводите два слова, интерфейс сразу показывает авто-разметку.
- **🔍 Поиск по одному слову** — мгновенно находит все пары и комбинации с этим словом. Регистр не важен: `Чай`, `ЧАЙ`, `чай` — одно и то же. Есть режим частичного совпадения (найдёт и «чайник» по запросу «чай») или точного совпадения.
- **🤖 Автоматическая категоризация** — пары сами распределяются:
  - по **группам и подкатегориям** (🍽️ Еда и напитки, 🐾 Животные, 🏙️ Места, 👔 Профессии, ⚽ Спорт и т.д. — на основе встроенного лексикона с распознаванием форм слов и регистра);
  - по **сложности** (Лёгкая / Средняя / Сложная / Эксперт — по смысловой близости и сходству написания: чем похоже, тем труднее шпиону).
  - Любую разметку можно **переопределить вручную** — при добавлении или через ✏️.
- **📚 Удобная база** — группировка по категориям или сложности, сворачиваемые блоки, фильтры, сортировки, счётчики.
- **🎲 Случайная пара** — вытянуть случайную пару прямо во время игры.
- **⬇⬆ Экспорт / импорт** JSON — перенос базы между устройствами (дубликаты отсеиваются, порядок слов не важен).
- Все данные хранятся **локально в браузере** (localStorage) — никакой сервер не нужен.

## Запуск

### На ПК (Windows)

Дважды щёлкните по файлу **`start_shpik.bat`** — он сам найдёт Python или Node.js на компьютере, запустит локальный сервер и откроет приложение в браузере по адресу http://localhost:8000. Остановка — закрыть чёрное окно сервера.

Если ни Python, ни Node.js не установлены, bat-файл просто откроет `index.html` — всё будет работать, но для надёжного хранения базы рекомендуется поставить [Python](https://www.python.org/downloads/) (при установке отметьте галочку **Add Python to PATH**).

### Любой другой способ

Это статический сайт — достаточно любого веб-сервера:

```bash
python3 -m http.server 8000
# и открыть http://localhost:8000
```

## Структура

```
index.html      — разметка
css/style.css   — оформление (тёмная тема, «стекло»)
js/lexicon.js   — лексикон для авто-категорий (можно дополнять)
js/logic.js     — нормализация, сходство слов, авто-сложность
js/app.js       — состояние, поиск, рендер, события
```
